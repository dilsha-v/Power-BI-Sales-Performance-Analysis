# Sales Performance Analysis – Power BI

## Project Overview
This project presents an interactive Sales Performance Analysis dashboard developed using Microsoft Power BI and embedded into a PowerPoint presentation.

The dashboard provides insights into sales performance, department-wise profitability, salesperson performance, and product-level analysis.

## Dashboard Pages
1. **Home:** Overall sales performance and key business indicators.
2. **Department Analysis:** Department-wise sales and profitability.
3. **Salesperson Analysis:** Individual salesperson performance.
4. **Product Analysis:** Product-level sales performance.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Microsoft PowerPoint

## Key Features
- Interactive dashboard navigation
- Dynamic filters and slicers
- KPI cards and performance indicators
- Sales and profitability analysis
- Interactive charts and tables
- Live Power BI report embedded in PowerPoint
